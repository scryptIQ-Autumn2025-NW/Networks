    Introduction

    Biological neural systems can be understood not only by examining individual neurons but also by analysing the structure of the networks they form. This section of the Networks 3 lesson extends our connectome analysis of C. elegans locomotion circuits, comparing the L1 larval and young adult (YA) connectomes through exploring how neuronal connectivity reorganises during development.

    Using the covered measures such as centrality, Personalised PageRank, and shortest paths, we identify neurons that become more or less influential as the locomotion circuit matures. We will then summarise these network-derived properties into structured datasets that can be used for further computational analysis and machine learning applications.

    Let's begin by importing packages and reading in our adjacency matrices.

    Edge changes between networks

    In NetworkX, if two graphs contain the same nodes, we can directly compare their edge structure. This can be done using the nx.difference() function, which returns a new graph containing only the edges that are present in one graph but not the other. We can then inspect these edges using the .edges attribute, chaining this onto the function.

    Let's try this with the L1 and YA connectomes, creating new networks with identical nodes, and inspecting and identifying changes in edges.

    # First, let's create a set of nodes shared between L1 and YA connectomes
shared_nodes = set(L1_connectome) & set(YA_connectome)

# Create new subgraphs based on the shared node set:
New_L1_connectome = L1_connectome.subgraph(shared_nodes)
New_YA_connectome = YA_connectome.subgraph(shared_nodes)

# Check if the nodes are the same between the two connectomes
print("Are nodes identical between connectomes? :", set(New_L1_connectome) == set(New_YA_connectome), "\n")

# Then we can peform the edge difference calculation
diff_edges = nx.difference(New_L1_connectome, New_YA_connectome).edges

# And printing the number and names of differential edges
print("These edges are different between the networks:", list(diff_edges)[:10], "\n") # The list truncates the output from filling the screen.
print("The number of differential edges:", len(diff_edges))

    Edge changes between networks with different nodes

    Whilst the nx.difference() function provides brief insight into the edge rewiring between the two networks (with identical nodes), the function itself cannot be utilised for comparing networks with different node sets.

    Importantly, nx.difference() also does not capture changes in node weights. Thus, a proper comparison of edges requires iteration across both networks. And we've already learnt how to do so from earlier materials.

    # First, we extract edges from each connectome
edges_L1 = set(L1_connectome.edges())
edges_YA = set(YA_connectome.edges())

# Then, we calculate all edges possible between the two networks (this include L1 or YA specific edges or shared edges)
all_edges = edges_L1 | edges_YA

    In NetworkX, the weight of a specific edge can be accessed with the following expression:

    $$w = G[u][v][\text{``weight''}]$$

    Where:

    • $G$ is the graph

    • $u$ is the start node

    • $v$ is the target node

    • $w$ is the edge weight

    Using this notation, we can iterate through all edges in a for loop and extract the corresponding weights (if present) from each network.

    # Firstly, create an empty dictionary too capture the edges
diff_edges = {}

# Secondly, loop through all the edges between L1 and YA connectomes
for u, v in all_edges:

    # Create a conditional statement, if edge is presented (and same direction), extract the weight.
    if (u, v) in edges_L1:
        w_L1 = L1_connectome[u][v]["weight"]
    # if not, assign weight as 0
    else:
        w_L1 = 0

    # Repeat for YA connectome
    if (u, v) in edges_YA:
        w_YA = YA_connectome[u][v]["weight"]
    else:
        w_YA = 0

    # Calculate the changes from L1 to YA
    differences = w_YA - w_L1

    # Store this difference to the dictionary with tuple as index
    diff_edges[(u, v)] = differences

    Conceptually, this for loop calculates the matrix for: $$∆ W$$

    This matrix can then be converted into a NetworkX graph. To do so, we can iterate through the dictionary and add these edges (with weight) to a directed graph: the delta network (or rewiring graph):

    # Firstly, create an empty directed graph
Delta = nx.DiGraph()

# Secondly, iterate through the different edges dictionary and add the weights into the DiGraph
for (u, v), delta in diff_edges.items():
    Delta.add_edge(u, v, weight=delta)

    And a summary of the differential edges in the delta network:

    pos_edges = []
neg_edges = []

for u, v, d in Delta.edges(data=True):
    if d["weight"] > 0:
        pos_edges.append((u, v, d["weight"]))
    elif d["weight"] < 0:
        neg_edges.append((u, v, d["weight"]))

print("Number of edges with increased weight:", len(pos_edges), "\n")
print("Number of edges with decreased weight:", len(neg_edges), "\n")

    RICL stands out as a rewiring hub because it is not only highly connected, but is strategically positioned at the intersection of sensory processing, neuromodulation and motor control. As a neuromodulatory integrator, RICL receives convergent input from diverse sensory and mechanosensory neurons and distributes modulatory output to multiple head motor circuits.

    This places it in a privileged position to coordinate early sensorimotor transformations. Between the L1 and YA stages, these pathways undergo substantial refinement, and RICL’s connectivity shifts accordingly. Its high degree centrality in the delta network reflects the fact that many of these developmental changes converge on or radiate from RICL, marking it as one of the principal nodes through which the maturing connectome reorganises its information flow.

    Similarly, SIBVR (right ventral SIB) and SIBVL (left ventral SIB) emerge as prominently connected nodes because of their foundational role in establishing the early head motor circuit. These neurons are generated very early in embryogenesis and help lay down the initial structural scaffold of the head network, providing stable reference points onto which later‑born neurons anchor their developing processes. As the connectome transitions from the simpler L1 architecture to the more refined YA configuration, the circuits surrounding SIBVL and SIBVR undergo substantial remodelling. Their early, highly connected position means they absorb a disproportionate share of synaptic additions, eliminations, and weight adjustments. This developmental centrality is reflected in their high degree centrality within the delta network, marking them as key loci through which the maturing head motor system reorganises its connectivity.

    Whilst we can extend this analysis to closeness centrality, one caveat of NetworkX is that closeness centrality analysis does not take negative values. This is because closeness centrality depends on shortest paths, and shortest paths with negative weights are invalid. To calculate closeness, we therefore need to convert the negative weights to positive weights.

    AbsDelta = nx.DiGraph()
for u, v, d in Delta.edges(data=True):
    AbsDelta.add_edge(u, v, weight=abs(d["weight"]))
    delta_closeness = nx.closeness_centrality(AbsDelta)
delta_closeness_df = pd.DataFrame.from_dict(delta_closeness, orient = "index")

    Network-derived properties for machine learning

    KEY TERMS

    • Machine learning (ML) is the field of data analysis in which algorithms learn patterns from data in order to make predictions, classifications, or discover structure without being explicitly programmed. While this has not been covered so far in the course, for those signed up for it, there is an entire module of the scryptIQ course dedicated to its exploration.

    • Clustering is an unsupervised machine-learning method that groups observations according to similarity in their features, allowing natural structure in the data to emerge. We mention it

    From network analysis to machine learning

    Taken together with the node centrality calculations introduced earlier in this lesson, we can summarise the structural properties of each neuron in a single Pandas DataFrame.

    Machine learning (ML) methods typically require data to be organised as a structured table of numerical features. Network-derived properties provide a natural bridge between graph analysis and machine learning because they convert each neuron from a position in a network into a set of quantitative descriptors.

    Measures such as in-degree, out-degree, centrality, and delta-based rewiring scores capture different aspects of how each neuron participates in the connectome and how its connectivity changes between the L1 and YA developmental stages.

    Preparing the data for clustering

    By combining these network-derived properties into a feature matrix—where each row represents a neuron and each column represents a network-derived measurement—we create a dataset suitable for machine-learning analysis.

    One useful application is clustering, which groups neurons according to similarity in their connectivity features. This can help reveal sets of neurons that share similar structural roles or patterns of developmental rewiring within the connectome.

    The code cells below prepare the data for these analyses by calculating multiple network-derived measures, aligning them across networks, and merging them into a single DataFrame. The final result is a clean, model-ready dataset in which each neuron is represented by a comparable set of biologically meaningful features.

    The cell below, for instance:

    • Calculates the in-degree and out-degree for every neuron in both the L1 and YA connectome networks

    • Converts the results into Pandas DataFrames so the degree values can be easily compared

    • Merges the L1 and YA results by neuron name, ensuring that all neurons from both networks are included

    • Computes the difference in degree between developmental stages (L1 − YA) for each neuron

    • Sorts the neurons by the absolute magnitude of the difference, highlighting those with the largest connectivity change

    # This code would have been executed in earlier part of the exercise:
L1_indegree = L1_connectome.in_degree()
L1_indegree_df = pd.DataFrame(list(dict(L1_indegree).items()), 
                              columns=['Node', 'In-Degree'])
YA_indegree = YA_connectome.in_degree()
YA_indegree_df = pd.DataFrame(list(dict(YA_indegree).items()), 
                              columns=['Node', 'In-Degree'])
Indegree_df = pd.merge(L1_indegree_df, 
                     YA_indegree_df, 
                     on='Node', ## joining by node name
                     how='outer') ## Take all possible nodes
Indegree_df.columns = ["Node","L1","YA"]
Indegree_df["Differences"] = Indegree_df["L1"] - Indegree_df["YA"]
Indegree_df = Indegree_df.reindex(Indegree_df['Differences'].abs().sort_values(ascending=False).index)


L1_outdegree = L1_connectome.out_degree()
L1_outdegree_df = pd.DataFrame(list(dict(L1_outdegree).items()), 
                              columns=['Node', 'Out-Degree'])
YA_outdegree = YA_connectome.out_degree()

                              columns=['Node', 'Out-Degree'])

                     YA_outdegree_df, 
                     on='Node', ## joining by node name
                     how='outer') ## Take all possible nodes

    Lastly, let's display the final DataFrame summarising the network-derived features calculated throughout this section.

    In summary constructing this DataFrame involved computing several structural measures for each neuron in both the L1 and YA connectomes, including in-degree, out-degree, and other centrality-based metrics. We then aligned the results by neuron name so that the same neurons could be directly compared between the two developmental stages. For each measure, the values from the L1 and YA networks were merged into a single table and a difference score was calculated to quantify how each neuron’s connectivity changed during development.

    The final DataFrame therefore represents a feature matrix in which each row corresponds to a neuron and each column contains a network-derived property or developmental change. This structured representation makes it possible to compare neurons systematically and prepares the connectome data for downstream analyses such as clustering or other machine-learning methods.

    KEY TERMS
