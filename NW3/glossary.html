Networks 3 - Glossary

Glossary NW3
Adjacency Matrix: A square matrix used to represent a network, where rows and columns correspond to nodes and each entry indicates whether a connection exists between them.
Directed Graph: A network in which edges have direction, meaning connections go from a source node to a target node.
Node (Vertex): An individual unit within a network, such as a neuron in a connectome.
Edge: A connection between two nodes representing an interaction or relationship.
In-Degree: The number of incoming connections to a node.
Out-Degree: The number of outgoing connections from a node.
Connectome: A complete map of neural connections within a nervous system.
Locomotion Circuit: A subset of neurons that coordinate forward and backward movement in *C. elegans*.
Shortest Path Analysis: A method used to determine the minimum number of steps or connections required to travel between two nodes in a network.
Personalised PageRank (PPR): A variant of PageRank that measures node influence while biasing importance toward specified starting nodes.
Developmental Connectome Comparison: The analysis of how network structure changes between developmental stages (e.g. L1 larva and young adult).
Rewiring (Network Rewiring): Changes in connections between nodes across networks or developmental stages.
Feature Matrix: A structured table where rows represent observations (e.g. neurons) and columns contain numerical features describing them.
Network-Derived Features: Quantitative measurements calculated from network structure (such as degree or centrality) used for further analysis.
Clustering: An unsupervised machine-learning technique that groups nodes according to similarity in their features.
