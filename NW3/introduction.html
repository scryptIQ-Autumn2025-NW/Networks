    Introduction NW3

    Welcome to Networks 3. Understanding how neurons are connected is essential for explaining how nervous systems generate behaviour. One powerful way to study neural organisation is through network analysis, in which neurons are treated as nodes in a graph and synaptic connections are represented as edges linking them. This framework allows us to apply mathematical and computational tools from graph theory to biological neural circuits, helping us quantify connectivity, identify influential neurons, and examine how network structure changes over time.

    In Networks 2, we previously examined the Breast Cancer Network (BCN) as a real-world example. In this lesson, we will apply these ideas to the well-studied Caenorhabditis elegans connectome: one of the few nervous systems for which a near-complete wiring diagram is available. Across the three sections that follow, we start out by constructing graph representations of the connectome and calculating basic structural properties such as neuronal degree. We then narrow our focus onto the locomotion circuit, exploring how signals propagate through key neurons, using techniques such as shortest path analysis and personalised PageRank (PPR). Finally, we extend the analysis by comparing connectomes from different developmental stages and extracting network-derived measurements that summarise how neuronal connectivity changes over time.

    Across all its sections, this lesson aims to demonstrate how graph-based analysis can reveal the structure, function and developmental dynamics of neural circuits, while also preparing the data in a form that can support more advanced analyses such as clustering or other machine-learning approaches (which we cover in depth, in the scryptIQ Machine Learning module).
